# External assets, private data and excluded files

Private project storage: [ATHN Google Drive](https://drive.google.com/drive/folders/1LRAvdL-bINHn_J3GLlWBMCYhTVNmJtwE). Request access from the project owner. Do not make the folder public merely to run the application.

## What is not committed

| Asset | Source / location | Local destination or restoration |
| --- | --- | --- |
| 55,000-image dataset | Drive Dataset/ (Reference, Same_Product, Unrelated, Manipulated) | ATHN_runtime/Dataset/; only original references are needed for inference |
| SSCD checkpoint | Drive Models/sscd_disc_mixup.torchscript.pt | ATHN_runtime/Models/sscd_disc_mixup.torchscript.pt |
| Reference embeddings | Drive Embeddings/reference_embeddings.pt | ATHN_runtime/Embeddings/reference_embeddings.pt |
| Evaluation embeddings | Drive Embeddings/{calibration_embeddings,test_embeddings,flipped_calibration}.pt | Optional research assets, same folder layout |
| Registry and frozen thresholds | Drive MetaData/registry.json and detection_config.json | ATHN_runtime/MetaData/ |
| Other metadata and per-image evaluation CSVs | Drive MetaData/ and Results/ | Optional research assets; same folder layout |
| Original Colab notebook with outputs | Drive Notebooks/ATHN_AI_Development.ipynb | Private research archive; a text source export is included in Git |
| SQLite snapshot | Drive athn.db | ATHN_runtime/athn.db (private restore only) |
| Newly registered images | Drive Dataset/Reference/registered/ | ATHN_runtime/Dataset/Reference/registered/ (matching snapshot only) |
| Verification evidence | Drive Evidence/ | ATHN_runtime/Evidence/ (matching snapshot only) |
| Private backend and frontend source snapshots | Drive Backend/ and Frontend_Updates/ | Historical backup only; use current Git source for new installs |
| Full/runtime backup ZIPs and local backup scripts | Local project archive if retained; not verified on Drive | Keep privately, never commit |
| Environment files and passwords | Local environment or hosting secret manager | backend/.env and frontend/.env.local from templates |
| Python and Node dependencies | Package registries | Reinstall with requirements.txt and npm ci |
| Build output, caches, Git metadata and temporary files | Generated locally | Recreate as needed; Git history is retained by the repository |

## Runtime tree

```text
ATHN_runtime/
  Dataset/Reference/        # required seed images; registered/ only with snapshot
  Models/sscd_disc_mixup.torchscript.pt
  Embeddings/reference_embeddings.pt
  MetaData/registry.json
  MetaData/detection_config.json
  athn.db                   # generated on first startup or restored privately
  Evidence/                 # generated by verification workflow
```

The remaining dataset categories, evaluation embeddings, original notebook, manifest files and raw results are only needed for research reproduction.

Drive inventory confirmed the expected model, four embedding files, seven metadata files, four results files, notebook/export, six backend files, three frontend updates, database and two registered photos. The dataset categories and sampled images were present; the individual 55,000-image count and byte-level integrity of all assets were not independently verified. The private backup is not a public data release.

For a clean installation, do not copy private evidence or the existing SQLite snapshot. Seed a fresh database instead. See [SETUP.md](SETUP.md) and [DATASET.md](DATASET.md).
