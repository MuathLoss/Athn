# IDHN UI/UX Production Rules — Non-negotiable

1. Arabic-first RTL. Do not design LTR and mirror at the end.
2. One primary task per screen, one primary action, secondary actions visually subordinate.
3. The product primitive is the Verification Trace / Evidence relationship — not generic cards.
4. No default KPI-card dashboard. Use task canvas, split evidence view, trace/timeline, data mode, focus mode when justified.
5. Most workspace stays light and neutral. Purple is a controlled signal, not wallpaper.
6. Gradients create depth/state transition only. No blob behind every component.
7. Glass/transparency is selective. No full-product glassmorphism.
8. No neon/cyberpunk/gaming aesthetic. No heavy dark mode as the primary experience.
9. No default AI brain/robot/sparkle language. Show AI through evidence, matching, trace, state and technical inspection.
10. No legal cliché as identity: no gavel, scales, courthouse columns, shield/check as the brand mark.
11. Show source information, AI evidence, system recommendation and user decision as distinct layers.
12. Similarity score is similarity, not probability of theft or legal guilt.
13. Decision text must be explicit: Authorized / Needs review / Unauthorized (or hold-for-review). Color is secondary.
14. Motion must explain causality. Use Content In → Verification → Permission Check → Decision as signature.
15. Provide reduced-motion equivalent.
16. Every page must have a distinct composition arising from its task.
17. Do not force every metric into a card; use annotations, editorial numbers, tables, or inline evidence.
18. Real states required: loading, success, error, no match, authorized, unauthorized, needs review, offline/permission denied where relevant.
19. Every visible control must work in the prototype/implementation.
20. Mobile is redesigned, not compressed desktop.
21. Aim for WCAG 2.2 AA. Visible keyboard focus required.
22. Long evidence/content reading must remain calm; decorative motion and saturated backgrounds step back.
23. Use fine linework, data-flow lines, editorial numbering, subtle texture and intentional white space when they serve the task.
24. Quality gate target: >=85/100 across originality, color/depth, trust/workflow clarity, motion, RTL/accessibility/mobile, engineering realism.
