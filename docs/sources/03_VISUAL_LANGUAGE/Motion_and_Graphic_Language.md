# IDHN Motion & Graphic Language Spec

## Motifs
### 1. Verification Wave
- Purpose: processing / transition / intelligence in motion.
- Appearance: low-amplitude lavender/purple flow, low opacity on white.
- Never: animated background noise during evidence reading.

### 2. Content Layers
- Purpose: content → reference → registry/evidence relationship.
- Derived directly from the gateway logo geometry.
- Can expand/contract contextually, but must preserve spatial continuity.

### 3. Decision Trace
- Purpose: causal path to a result.
- Fine line with one key node; can anchor annotations, score, registry state or final decision.

## Signature sequence
1. Content In — source enters the verification field.
2. Verification — layer relationship forms; trace begins.
3. Permission Check — node pauses/highlights at registry/authorization check.
4. Decision — trace resolves to Authorized / Needs review / Unauthorized.

## State motion
- Authorized: trace resolves cleanly; state appears once. Avoid celebratory confetti.
- Needs review: trace pauses; amber state + next action/context.
- Unauthorized/Hold: trace stops; red state + review/hold explanation. Avoid alarmist shake animation.

## Durations
- hover/press: 120–160ms
- local reveal: 180–240ms
- panel/context: 240–320ms
- major shared-element transition: 260–350ms
- signature sequence: 600–900ms max, non-blocking

## Reduced motion
No travel/parallax. Keep state swap + text/icon change <=120ms. All information must remain available without animation.
