# Asset note

The approved visual reference originated as a rendered concept board, not as an original vector design file. The SVG assets in this package are a **clean production reconstruction of the approved geometry and meaning** (layered gateway, verification trace, central node), prepared specifically so the project has editable source assets.

For any future micro-adjustment to exact corner geometry, optical spacing, or wordmark drawing, update the SVG master first, then re-export all PNG variants and increment the package version.
