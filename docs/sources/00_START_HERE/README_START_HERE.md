**Status:** Approved source package

**Primary use:** LegalTech hackathon product — preventive AI-assisted copyright verification.

## Start here
This archive is the single source of truth for the current approved visual identity and interface direction.

### What is approved
- **Logo concept:** two layered gateways + horizontal verification trace + central decision node.
- **Meaning:** `Content → Verification Layer → Permission Decision`.
- **Identity mode:** Light-first. White / near-white canvas with restrained Lavender atmosphere.
- **Brand colors:** Obsidian, Charcoal, Royal Purple, Stone Purple, Soft Stone + white.
- **Signature visual language:** Verification Wave, Content Layers, Decision Trace.
- **Motion signature:** Content In → Verification → Permission Check → Decision.
- **Decision states:** Authorized / Needs review / Unauthorized — always communicated with text + icon/context, not color alone.
- **Arabic-first:** RTL is designed from the start, not mirrored after LTR.

### Important governance
- `AI Copyright Verification` is a **supporting descriptor**, not a mandatory part of the master logo lockup.
- Do not claim the similarity score is a “probability of theft”. It is a similarity signal and the product decision layer uses registry/authorization context.
- AI is supportive: it identifies visual evidence/matches; it does not independently determine legal ownership or infringement.
- Never replace the master logo with a shield/check/fingerprint/eye/gavel/scales/robot/brain cliché.
