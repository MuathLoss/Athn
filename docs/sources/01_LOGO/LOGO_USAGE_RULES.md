# Logo Production Rules

**Master concept is fixed:** layered gateway + verification trace + central decision node.

## Clear space
Minimum clear space = one central-node width on all sides. For signage/hero applications use 1.5–2× where possible.

## Minimum sizes
- Symbol digital: 24px minimum; prefer 32px+.
- Horizontal lockup digital: 140px wide minimum.
- Print symbol: 10mm minimum.
- If the wordmark loses legibility, switch to symbol-only.

## Backgrounds
Preferred: white, soft lavender-white, or controlled Obsidian for inverse use.
Do not place the detailed gradient/glass symbol over busy photography without a quieting field.

## Never
- stretch/squash;
- rotate/skew the completed mark;
- swap purple for random hues;
- remove or move the decision node;
- add glow/neon;
- add shields/checks/scales/gavels;
- place the logo inside a generic badge unless it is the approved app-icon construction;
- use the descriptor as mandatory logo text.
