# ATHN frontend

Arabic React/TypeScript/Vite interface for sellers, rights holders and reviewers. See [project README](../README.md) and [setup](../docs/SETUP.md). Original design references are in [docs](../docs/).

Use npm ci, copy .env.example to .env.local for live mode, and run npm run dev. Without API variables the development fixtures remain available for existing browser tests. Mock credentials are non-secret test fixtures and must not be reused on the live backend.
